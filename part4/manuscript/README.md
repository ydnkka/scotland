# Manuscript Figures - Part 4

This directory contains publication-ready figure exports and narrative summary
files for the Part 4 Alpha emergence analysis. Figures are generated by:

```bash
conda run -n PhD python part4/manuscript/make_figures.py
```

The plotting script uses the shared project style module at `utils/style.py`,
policy definitions from `utils/policy.py`, and Part 4 CSV tables in
`part4/tables/`.

## Figure Set

- `fig1_alpha_geographic_emergence`: Regional expansion summary for Alpha.
  Panel A shows phase-level unique sequence counts and the number of affected
  health boards; Panel B shows a health-board-by-phase heatmap. Exports: PDF,
  PNG, and LZW-compressed TIFF.
- `fig2_alpha_b1177_transition`: Mutation-marker and lineage-composition time
  series showing Alpha replacing B.1.177, with policy context and hospital
  occupancy. Exports: PDF, PNG, and LZW-compressed TIFF.
- `fig3_counterfactual_growth`: Counterfactual L2-timing projections and
  fitted Alpha/B.1.177 growth-rate comparison. Exports: PDF, PNG, and
  LZW-compressed TIFF.

## Narrative Files

- `part4_results_and_figures_description.md`: figure-by-figure manuscript
  guidance and suggested results paragraphs.
- `part4_summary_report.md`: concise Part 4 report with embedded figure
  previews, demographic summaries, overlap evidence, and model interpretation.

## Notes

The Figure 1 heatmap uses health-board aggregated unique sequence counts, not
summed cluster memberships. This matters for the early Alpha phases because
overlapping windows can carry the same sequences into multiple clusters. The
demographic interpretation in the summary report therefore prioritises the
unique-sequence fields in `part4_alpha_phase_demographic_summary.csv`.

The primary growth model fits a binomial GLM to the sequenced S:N501Y counts,
with additional window-level weighting by confirmed positive-test volume. The
sensitivity table `part4_growth_model_sensitivity.csv` compares that model
with an unweighted binomial GLM and a coverage-adjusted GLM that includes the
proportion of positives sequenced.

The counterfactual projections are descriptive fitted scenarios. They are
useful for asking whether earlier L2-level restrictions could plausibly have
changed the timing of Alpha dominance, but they should not be treated as
causal estimates of policy effectiveness.
