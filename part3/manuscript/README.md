# Manuscript Figures - Part 3

This directory contains publication-ready figure exports for the Part 3 policy
and variant-phase analysis.  Figures are generated by:

```bash
conda run -n PhD python part3/manuscript/make_figures.py
```

The plotting script uses `utils/style.py` and writes PDF, PNG, and
LZW-compressed TIFF versions to `figures/`.

## Figure Set

### Main figures

- `fig1_policy_timeline_cluster_structure`: weekly median log cluster size
  across the epidemic with policy-period shading and transition markers.
- `fig2_selected_policy_transitions`: plus/minus 8-week ITS plots for `T1`,
  `SL`, and `NN`, showing median log cluster size and median log datazones.
- `fig3_alpha_emergence_f5_l2`: `S:N501Y` and `S:A222V` frequencies plus
  health-board expansion of Alpha during the `F5/L2` bridge.
- `fig4_alpha_counterfactual_timing`: fitted and counterfactual `S:N501Y`
  trajectories under earlier L2 timing, with growth-rate comparison.

### Supplementary figures

- `supp_fig1_its_mixing_outcomes`: plus/minus 8-week ITS plots for SIMD and
  age excess-discordance outcomes.

## Notes

Run `part3/part3_analysis.py` before rendering figures.  The figure script reads
only generated Part 3 tables and does not rebuild the analysis.
