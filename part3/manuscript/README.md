# Manuscript Figures — Part 3

This directory contains publication-ready figure exports for the Part 3 policy
period analysis. Figures are generated by:

```bash
conda run -n PhD python part3/manuscript/make_figures.py
```

The plotting script uses the shared project style module at `utils/style.py`
and writes PDF, PNG, and LZW-compressed TIFF versions to `figures/`.

Tables required by the figure script are pre-computed by `part3/part3_analysis.py`
and cached in `part3/tables/`. Run the analysis script first if the tables are
absent or stale.

The accompanying narrative description is
`part3_results_and_figures_description.md`.

## Figure Set

### Main figures

- `fig1_weekly_time_series`: Two-panel weekly time series annotated with
  policy period shading (colour-coded by intensity). Panel A shows weekly
  median log cluster size for non-singleton clusters; Panel B shows the
  policy intensity stepped series with period code labels. Vertical dashed
  lines mark the three ITS transition dates.

- `fig2_its_transitions`: 3×2 interrupted-time-series panel. Rows correspond
  to the three chosen transition points (T1-onset Oct 2020, L2→SL Apr 2021,
  NN-onset Aug 2021). Left column shows median log cluster size; right column
  shows median log datazones. Each panel plots pre/post weekly data points
  with fitted OLS segmented-regression lines and an annotated level-change
  estimate (β_post with 95 % CI; starred if p < 0.05).

- `fig3_period_outcomes`: Horizontal dot chart of median log cluster size
  (left panel) and median log datazones (right panel) for each observed policy
  period, ordered chronologically. Points are coloured by policy intensity
  using the RdYlBu_r scale with a shared colourbar.

### Supplementary figures

- `supp_fig1_weekly_mixing`: 2×2 weekly time series panel showing (A) mean
  SIMD excess discordance, (B) mean age excess discordance, (C) median log
  datazones, and (D) policy intensity over the full study period, with
  background period shading and ITS transition marker lines.

## Notes

All figures read exclusively from `part3/tables/` CSV files. The analysis
script (`part3/part3_analysis.py`) produces these tables from the Part 1 main
cluster cache at `part1/main/cache/main_cluster_table.parquet`.

The Part 3 analysis is descriptive characterisation of policy–cluster
associations. Policy periods are strongly confounded with variant waves and
calendar time; no causal inferences are drawn. See
`part3_analysis_documentation.md` for full implementation details.
