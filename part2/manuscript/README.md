# Manuscript Figures — Part 2

This directory contains publication-ready figure exports for the Part 2
vaccination characterisation analysis. Figures are generated by:

```bash
conda run -n PhD python part2/manuscript/make_figures.py
```

The plotting script uses the shared project style module at `utils/style.py` and
writes PDF, PNG, and LZW-compressed TIFF versions to `figures/`.

The accompanying narrative description is
`part2_results_and_figures_description.md`.

## Figure Set

### Main figures

- `fig1_vaccinated_cases_over_time`: proportion of sequenced cases who were
  vaccinated by calendar week, stratified by JCVI rollout age group (panel A)
  and overall SIMD deprivation quintile (panel B).
- `fig2_cluster_vaccination_by_wave_and_category`: cluster vaccination profile
  (none/mixed/all vaccinated) by wave (panel A) and mean cluster proportion
  vaccinated by wave and cluster size category (panel B).
- `fig3_vaccination_mixing_by_wave`: vaccination-status mixing category
  (homogeneous/baseline/mixed) by epidemic wave, for non-singleton clusters.
- `fig4_demographic_mixing_by_wave`: stacked proportional bars for SIMD
  deprivation, age, sex, and joint-profile mixing categories by wave (2×2
  panel). Requires `part2/cache/cluster_categories.parquet`.
- `fig5_geographic_dispersion_by_wave`: geographic dispersion category by wave
  (panel A) and mean cluster proportion vaccinated by wave and dispersion
  category (panel B).
- `fig6_dose_recency_by_simd`: heatmaps of mean booster coverage (panel A) and
  mean days since last prior vaccination (panel B) by wave and overall SIMD
  quintile.

### Supplementary figures

- `supp_fig1_weekly_mixing_evolution`: smoothed weekly stacked-area chart of
  vaccination-status mixing category fractions over the full study period.
- `supp_fig2_domain_dose_gradient`: heatmaps of the Q5 − Q1 deprivation
  gradient in booster coverage (panel A) and days since last dose (panel B) by
  SIMD domain and wave.
- `supp_fig3_cross_category_heatmap`: 2×2 heatmap of the fraction of
  non-singleton clusters classified as "more mix" for SIMD deprivation, age,
  sex, and joint-profile mixing, by SIMD quintile and cluster size category.
  Requires `part2/cache/cluster_categories.parquet`.
- `supp_fig4_cross_category_less_mix_heatmap`: same layout as supp_fig3 but
  showing the fraction classified as "less mix".
  Requires `part2/cache/cluster_categories.parquet`.

## Notes

Figures 4, supp_fig3, and supp_fig4 require `pyarrow` to read the parquet
caches. They are skipped gracefully if `pyarrow` is not available and a warning
is printed. In the PhD conda environment `pyarrow` is installed by default.

All other figures read from `part2/tables/` CSV files and have no additional
dependencies beyond the standard scientific Python stack (numpy, pandas,
matplotlib, seaborn).

The Part 2 analysis is descriptive characterisation rather than causal
vaccine-effectiveness estimation. See `part2_analysis_documentation.md` for
full implementation details.
