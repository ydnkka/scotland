# Chapter 1 Manuscript Planning

This directory holds manuscript-planning material for the Chapter 1 cluster
scale and sociodemographic mixing analysis.

- `figure_table_plan.md` gives the proposed main and supplementary figure and
  table package, including panel structure, required input files, and the
  interpretation role of each item.

The plan is intentionally Chapter 1 specific: it learns from the Part 1
manuscript structure but does not try to reproduce the Part 1 figure set.
